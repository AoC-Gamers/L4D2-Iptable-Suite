# Análisis de logs

Consulta [la guía canónica](../docs/observability/log-summary.md) para resumen
ligero, informes detallados, configuración Compose y gestor venv. Los analizadores
siguen disponibles; los manuales antiguos se conservan como referencia histórica.
No mezcles variables de logging con configuración del firewall ni uses su menú
privilegiado de rsyslog como diagnóstico pasivo.

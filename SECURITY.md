# Comunicación de problemas de seguridad

Consulta [la aprobación con observaciones](docs/security/approval.md) y
[los límites conocidos](docs/security/limitations.md) antes de interpretar cobertura.
La aceptación registrada no es certificación externa ni aprobación automática de
otros commits o despliegues.

El [repositorio de GitHub](https://github.com/AoC-Gamers/L4D2-Iptable-Suite) tiene
[issues públicos](https://github.com/AoC-Gamers/L4D2-Iptable-Suite/issues).
Al revisar la API el 12 de octubre de 2026, private vulnerability reporting estaba
desactivado; no se confirmó un canal privado de seguridad. No se prometen tiempos
de respuesta ni recompensas.

Para un problema no sensible, comunica versión/commit, configuración mínima ficticia,
resultado esperado/observado y evidencia saneada del entorno aislado. Si el hallazgo
requiere detalles sensibles, solicita primero un canal privado a los mantenedores
sin describir públicamente la explotación. No publiques secretos, `.env`, tokens,
claves, capturas de terceros ni logs que identifiquen usuarios o redes reales.
No reproduzcas un fallo alterando el firewall que mantiene el acceso al entorno.
